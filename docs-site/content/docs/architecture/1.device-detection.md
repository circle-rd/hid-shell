---
title: Device detection
description: How HID-Shell finds and disambiguates the Vandal agent among all the HID devices on a host.
---

The hardest problem in finding "the" device is that the Vandal vendor usage page is **not unique**. The pair `(usage page 0xFF00, usage 0x01)` is extremely common — RGB controllers, gaming dongles, and hobbyist Arduino boards all advertise it. HID-Shell therefore never just "takes the first match." It **probes** each candidate to confirm it is talking to the Vandal agent.

All of this lives in `src/transport_hid.nim`.

## Why not filter by VID/PID?

VID/PID filtering would be simpler, but Vandal lets the operator **reconfigure VID/PID at runtime**. The usage page is the stable, always-present identity, so HID-Shell filters on that instead.

## Enumeration and probing

`findVandalShell()` walks every HID device on the host:

1. Call `hid_enumerate(0, 0)` to list all devices.
2. Keep only those with `usagePage == 0xFF00` and `usage == 0x01`.
3. For each candidate, `hid_open_path()` it and run a HELLO probe (`probeIsVandal()`).
4. The first candidate that answers is returned; the rest are closed.

### The HELLO probe

`probeIsVandal()` sends a single `CTRL` frame of subtype `HELLO` carrying the protocol version and the host OS identifier, then waits for a `HELLO_ACK`:

- **Per-read budget:** `ProbeTimeoutMs = 250` ms.
- **Total budget:** `ProbeMaxReads = 6` reads, ≈ 1.5 s before giving up on a candidate.
- **Success:** a `CTRL` frame whose first payload byte is `HELLO_ACK` (`0x02`).
- **Any other frame or timeout:** keep waiting until the budget is exhausted, then try the next candidate.

Writing a 4-byte vendor-page report into a foreign HID device is generally harmless — the receiver either ignores it (no matching report-descriptor handler) or replies with garbage that gets discarded.

## Waiting for the device

At startup the launcher fires the payload before the agent has necessarily finished enumerating its vendor interface, so HID-Shell polls:

```nim
waitForDevice(maxAttempts = 50, intervalMs = 200, debug = ...)
```

Each attempt is a full `findVandalShell()` scan; `intervalMs` is the sleep between scans. `main()` derives `maxAttempts` from the `--wait-ms` value (`maxAttempts = max(1, waitMs div 200)`), so the default 20 s wait becomes up to 100 scans at 200 ms apart.

If the wait window elapses with no confirmed agent, `waitForDevice()` returns `none` and the process exits with status **3**.
