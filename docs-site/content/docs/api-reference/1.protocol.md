`src/protocol.nim` defines the wire-protocol constants and frame helpers. It is a pure module with no I/O.

## Types

### `Frame`

The in-memory representation of one wire frame:

```nim
type
  Frame* = object
    typ*: uint8
    flags*: uint8
    seq*: uint16
    payload*: array[FramePayloadSize, uint8]
    payloadLen*: int  ## significant bytes in `payload`
```

## Constants

| Constant           | Value  | Description                                     |
| ------------------ | ------ | ----------------------------------------------- |
| `FrameSize`        | `64`   | Total bytes per wire frame.                     |
| `FrameHeaderSize`  | `4`    | Size of the `type` + `flags` + `seq` header.    |
| `FramePayloadSize` | `60`   | Maximum significant payload bytes per frame.    |
| `TypeCmd`          | `0x10` | agent → host command bytes.                     |
| `TypeOut`          | `0x11` | host → agent shell output bytes.                |
| `TypeCtrl`         | `0x12` | bidirectional control message.                  |
| `FlagFin`          | `0x01` | FIN — last fragment of a logical message.       |
| `FlagLenShift`     | `2`    | Left shift of the length field inside `flags`.  |
| `FlagLenMask`      | `0x3F` | 6-bit length field (0..60).                     |
| `CtrlHello`        | `0x01` | HELLO subtype.                                  |
| `CtrlHelloAck`     | `0x02` | HELLO_ACK subtype.                              |
| `CtrlPing`         | `0x03` | PING subtype.                                   |
| `CtrlPong`         | `0x04` | PONG subtype.                                   |
| `CtrlCmdId`        | `0x05` | CMD_ID subtype.                                 |
| `CtrlBye`          | `0x06` | BYE subtype.                                    |
| `CtrlError`        | `0x07` | ERROR subtype.                                  |
| `OsWindows`        | `0x01` | OS identifier — Windows.                        |
| `OsLinux`          | `0x02` | OS identifier — Linux.                          |
| `OsMacOS`          | `0x03` | OS identifier — macOS.                          |
| `ProtoVersion`     | `0x0001` | Protocol version.                              |
| `VendorUsagePage`  | `0xFF00` | Vendor HID usage page used to filter devices.  |
| `VendorUsage`      | `0x0001` | Vendor HID usage used to filter devices.       |

## Procedures

### `encodeFrame`

```nim
proc encodeFrame*(f: Frame): array[FrameSize, uint8]
```

Serialise `f` into a 64-byte wire frame, zero-padded. The payload length is encoded in the high bits of `flags` (`FlagLenShift` / `FlagLenMask`) so the receiver recovers the exact number of significant bytes without scanning for NULs.

### `decodeFrame`

```nim
proc decodeFrame*(buf: openArray[uint8]): Frame
```

Parse a 64-byte wire frame. `payloadLen` is recovered from the high bits of `flags`; `flags` is stripped down to the low control bits (FIN + reserved).

### `isFin`

```nim
proc isFin*(f: Frame): bool {.inline.}
```

`true` when the FIN flag is set on the frame.
