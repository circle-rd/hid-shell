`src/transport_hid.nim` is the high-level transport over the Vandal vendor HID interface. It uses the minimal FFI binding in `src/hidapi_ffi.nim` to the system hidapi library and filters HID devices by usage page `0xFF00` (rather than VID/PID) because Vandal allows those to be reconfigured at runtime.

## Types

### `HidLink`

An open handle to the Vandal vendor HID interface:

```nim
type
  HidLink* = object
    dev*: HidDevice   ## opaque hidapi handle
    path*: string
    vid*: uint16
    pid*: uint16
```

## Procedures

### `findVandalShell`

```nim
proc findVandalShell*(debug: proc(msg: string) = nil): Option[HidLink]
```

Walk every HID device on the host, narrow to the ones exposing the Vandal vendor usage `(0xFF00, 0x01)`, then **probe** each candidate with a HELLO frame to confirm it is actually the agent. The vendor `(0xFF00, 0x01)` combo is common (RGB controllers, gaming dongles, hobbyist Arduino boards), so "take the first match" regularly opened the wrong device. Probing is the only reliable signature, since Vandal lets users reconfigure VID/PID at runtime.

### `waitForDevice`

```nim
proc waitForDevice*(maxAttempts = 50, intervalMs = 200,
                    debug: proc(msg: string) = nil): Option[HidLink]
```

Poll until either the Vandal shell vendor HID is found or the attempt budget is exhausted. Used at startup so the launcher can fire the payload before the agent finishes enumerating.

### `sendFrame`

```nim
proc sendFrame*(link: HidLink, f: Frame): bool
```

Write one 64-byte report. Returns `true` on success. The descriptor has no report ID, so a leading `0x00` byte is prepended as required by hidapi.

### `readFrame`

```nim
proc readFrame*(link: HidLink, timeoutMs: int = 100): Option[Frame]
```

Block up to `timeoutMs` waiting for one report. Returns `none` on timeout, raises `IOError` on a fatal device error. The buffer is always sized `FrameSize + 1` and the leading report-ID byte (present when the platform prepends one) is stripped if present, so all three platforms share one code path.

### `close`

```nim
proc close*(link: HidLink)
```

Close the underlying hidapi device handle.

## Internal probe helpers

These are not exported but are central to device disambiguation:

| Procedure | Budget | Description |
| --------- | ------ | ----------- |
| `sendProbeHello(link)` | — | Send a 4-byte `HELLO` (`CtrlHello`, proto version LE, host OS id). |
| `probeIsVandal(link, debug)` | `ProbeTimeoutMs = 250` ms per read, `ProbeMaxReads = 6` reads (≈ 1.5 s) | Wait for a `HELLO_ACK`; `false` on write fail, read fail, timeout, or an unrelated frame. |
