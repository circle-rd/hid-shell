`src/hidapi_ffi.nim` provides minimal FFI bindings for the system `hidapi` C library. The project avoids pulling a third-party Nim wrapper because the existing `hidapi` nimble package is unmaintained/unpublished, and the C surface actually needed is tiny: enumerate, open_path, read_timeout, write, close.

## Two linking modes

The mode is switched by the `-d:hidapiStatic` Nim define:

- **Default (dev):** `dynlib` — dlopen the system hidapi at runtime. Convenient for `nim r` iteration on a dev box that already has `libhidapi-hidraw0` / `brew install hidapi` / a bundled DLL.
- **`-d:hidapiStatic` (release):** plain `importc` — the linker resolves the symbols against a static `libhidapi.a` provided via `--passL`. This is what `./scripts/build_all.sh` uses so the shipped binaries have no hidapi runtime dependency on the target host.

Static-mode runtime dependencies per target:

- **Linux:** `libudev` (part of systemd — universal on modern desktops)
- **macOS:** `IOKit` + `CoreFoundation` (system frameworks, always present)
- **Windows:** `setupapi.dll` + `hid.dll` (system DLLs, always present)

## Types

### `HidDevice`

An opaque handle returned by `hid_open*`:

```nim
type
  HidDevice* = pointer
```

### `HidDeviceInfo`

A single entry in the enumeration list:

```nim
type
  HidDeviceInfo* {.bycopy.} = object
    path*: cstring
    vendorId*: cushort
    productId*: cushort
    serialNumber*: ptr WideCString
    releaseNumber*: cushort
    manufacturerString*: ptr WideCString
    productString*: ptr WideCString
    usagePage*: cushort
    usage*: cushort
    interfaceNumber*: cint
    next*: ptr HidDeviceInfo
```

## C symbols

| Procedure | Description |
| --------- | ----------- |
| `hid_init()` | Initialise the hidapi library. |
| `hid_exit()` | Shut the hidapi library down. |
| `hid_enumerate(vendorId, productId)` | Return the linked list of matching devices (`(0, 0)` for all). |
| `hid_free_enumeration(devs)` | Free an enumeration list. |
| `hid_open_path(path)` | Open a device by its platform path. |
| `hid_close(dev)` | Close a device handle. |
| `hid_write(dev, data, length)` | Write a report; returns the number of bytes written. |
| `hid_read_timeout(dev, data, length, milliseconds)` | Read a report with a timeout; negative on error, `0` on timeout. |
| `hid_error(dev)` | Last error for the device (or global if `nil`), as a wide string owned by hidapi — do not free. |
