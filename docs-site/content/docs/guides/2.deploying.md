---
title: Deploying to an agent
description: Download, verify, and upload the HID-Shell payloads to a Vandal agent so the shell channel can be brought up.
---

HID-Shell is deployed **once per agent**, not per host. The binaries live on the agent's FAT volume and persist across reboots; the agent's launcher picks the right one for whatever host the device is plugged into.

## Step 1 — Get the binaries

Download the three assets (plus `SHA256SUMS`) from a [GitHub Release](https://github.com/circle-rd/hid-shell/releases), or build them yourself (see [Building](/hid-shell/docs/guides/1.building)).

## Step 2 — Verify and rename

The Vandal universal launcher expects short, fixed filenames on the agent's `/payloads/` volume:

| Asset                          | Target           | Rename to |
| ------------------------------ | ---------------- | --------- |
| `hid_shell-linux-x86_64`       | Linux x86_64     | `sl`      |
| `hid_shell-macos-arm64`        | macOS arm64      | `sm`      |
| `hid_shell-windows-x86_64.exe` | Windows x86_64   | `sw.exe`  |

Verify and rename in one go:

```sh
sha256sum -c SHA256SUMS
mv hid_shell-linux-x86_64        sl
mv hid_shell-macos-arm64         sm
mv hid_shell-windows-x86_64.exe  sw.exe
```

## Step 3 — Upload to the agent

Upload each file to `/payloads/` on the Vandal agent via the web UI (**BadUSB → File transfer**). One upload per file, one time per agent.

## Step 4 — Bring up the shell

From the agent's *Shell* page:

1. Click **Prepare** — the BFF streams the universal DuckyScript launcher inline (~2 KB, a single MQTT message).
2. Click **Start** — the agent injects the launcher as HID keystrokes, the launcher execs the matching `sl` / `sm` / `sw.exe` silently (no terminal window on any OS), HID-Shell connects and spawns the shell, and the bidirectional channel comes up.
3. Type commands in the web UI. Click **Stop** to make the agent send `BYE`; HID-Shell tears down the shell and exits.

## Host runtime requirements

Remember the macOS binary needs `brew install hidapi` on the host. Linux and Windows binaries are self-contained (beyond their universal system pieces). See [Installation](/hid-shell/docs/getting-started/2.installation) for the full per-platform table.
