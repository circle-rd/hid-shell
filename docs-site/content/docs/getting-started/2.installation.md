HID-Shell ships as a single self-contained binary per platform. In the standard deployment you do **not** install it on the host at all — you upload it once to a Vandal agent's `/payloads/` volume and the agent's launcher picks the right one. This page covers both getting a pre-built binary and building your own.

## Pre-built binaries

Each tagged GitHub Release publishes the three cross-compiled payloads, a `SHA256SUMS` manifest, and a generated `RELEASE_NOTES.md`:

| Asset                          | Target           | Rename to (agent `/payloads/`) |
| ------------------------------ | ---------------- | ------------------------------ |
| `hid_shell-linux-x86_64`       | Linux x86_64     | `sl`                           |
| `hid_shell-macos-arm64`        | macOS arm64      | `sm`                           |
| `hid_shell-windows-x86_64.exe` | Windows x86_64   | `sw.exe`                       |

Verify and rename in one go:

```sh
sha256sum -c SHA256SUMS
mv hid_shell-linux-x86_64        sl
mv hid_shell-macos-arm64         sm
mv hid_shell-windows-x86_64.exe  sw.exe
```

Then upload the three files to `/payloads/` on the agent (Vandal web UI → **BadUSB → File transfer**). One upload per agent — the binaries persist on the FAT volume across reboots.

## Runtime dependencies on the host

The amount the binary needs from the target host differs per platform:

| Platform | Host runtime dependencies |
| -------- | ------------------------- |
| Linux x86_64        | `libudev` (part of systemd — universal on modern desktops), libc |
| macOS arm64         | `libhidapi.dylib` — install with `brew install hidapi`, plus Apple's IOKit/CoreFoundation (system) |
| Windows x86_64      | `setupapi.dll`, `hid.dll` (Windows built-ins) |

The Linux and Windows binaries statically link hidapi, so those hosts need **nothing user-installed** beyond the system pieces above. The macOS binary keeps a runtime-dlopen path because hidapi's macOS backend requires Apple's Xcode SDK headers, which cannot be legally redistributed. See [Building](/hid-shell/docs/guides/1.building) for the opt-in fully-static macOS build.

## Prerequisites to build from source

To build HID-Shell yourself you need:

- **Nim ≥ 2.0** with `nimble` (the project declares `requires "nim >= 2.0.0"` in `hid-shell.nimble`).
- The system **hidapi** library, unless you build inside the project Dockerfile which bundles it:
  - Debian/Ubuntu: `sudo apt install libhidapi-hidraw0`
  - Fedora: `sudo dnf install hidapi`
  - macOS: `brew install hidapi`
  - Windows: drop `hidapi.dll` next to the built `.exe`

For the recommended zero-setup path, see [Building with Docker](/hid-shell/docs/guides/1.building).
